# 運用方針

## 目的

本サイトは、自動収集ではなく人による確認を基本とします。この文書は、公式情報への案内を安全かつ継続可能な範囲で維持するための確認頻度、状態管理、公開履歴、情報量上限を定めます。

第一版は未実装です。以下は2026年8月1日時点の運用設計であり、実運用の結果に応じて理由と影響範囲を記録したうえで見直します。

## 確認頻度

### 常設主リンク

原則として週1回、次を確認します。

- ページが正常に開くか
- 公式サイトから外れていないか
- ページの役割が変わっていないか
- 古い災害情報だけのページになっていないか

### 補助リンク

原則として月1回確認します。主な対象は次のとおりです。

- 公式SNS
- LINE・メール登録案内
- 公式性の確認根拠
- 補助的な通報・相談案内
- 道路カメラ
- バス位置情報

### 表示中の期間限定リンク

原則として週1回確認し、状況に応じて臨時確認します。自動取得や自動表示・非表示は行いません。

## 確認日の意味

### 案内先確認日

URLが開くこと、公式サイトから外れていないこと、案内目的に合うことなどを確認した日です。リンク先のすべての内容の正確性や、現在の災害・運行・供給状況を保証する日ではありません。

### 公式性確認日

団体公式サイトからのリンク、公式SNS一覧、公式のお知らせなど、掲載基準に基づく公式性の根拠を確認した日です。認証バッジやフォロワー数だけを確認した日ではありません。

### サイト全体の最終点検日

定めた確認対象について、サイト全体の表示、主要導線、常設主リンク、期間限定リンクの状態、重要な文言などを一巡して点検した日です。全リンク先の内容や現在状況の正確性を保証するものではありません。

## 期間限定リンクの状態

| 状態 | 意味 | 公開画面 |
| --- | --- | --- |
| 掲載中 | 人が現在有効と確認し、表示している | 表示する |
| 終了確認中 | 終了または役割変更の可能性があり、再確認している | 原則として目立つ案内から外す |
| 非表示・管理記録へ保存 | 公開表示を終了し、必要な管理記録だけ保持する | 表示しない |

期間限定リンクは、人が現在有効であることを確認した期間だけ表示します。災害別の深いURLを固定リンクとして恒久的に残しません。非表示は災害や支援の終了、安全、復旧を本サイトが判断したことを意味しません。

## URL変更・エラー時の扱い

1. 404、リダイレクト、アクセス不能、役割変更を確認する
2. 団体の公式トップページや公式サイト内の案内から移転先を調べる
3. 公式性と案内目的を再確認する
4. 根拠、対象URL、案内先確認日、公式性確認日を必要に応じて更新する
5. 確認できるまで保留または非表示にする
6. 公開対象となる変更を確認・更新履歴へ記録する

非公式の転載ページや検索結果だけを代替リンクにしません。リンク切れを理由に、現在状況を本サイトへ転載しません。

## 更新履歴

### 公開する内容

- サイト全体の最終点検日
- 定期確認を行った事実と対象範囲
- URL変更
- 新規追加
- 期間限定リンクの掲載・終了
- 一時保留
- 重要な掲載方針変更

### 公開しない内容

- 作業中の内部メモ
- 公式性を確認していないURL
- 公開前の候補情報
- 個人情報やセンシティブ情報
- セキュリティ上公開すべきでない情報
- 問い合わせに含まれる個人情報

公開履歴は、本サイトの確認作業を透明にするための記録です。リンク先の内容の正確性や現在状況を保証する証明ではありません。

## 情報量の上限

第一版では次を運用上の目安とします。

| 対象 | 上限・目安 |
| --- | --- |
| 公開画面上のまとまり | 約17 |
| 管理する情報源 | 30件以内 |
| 常設・補助リンク | 45件以内 |
| 同時に表示する期間限定リンク | 8件以内 |
| 一つのカードの主ボタン | 原則1〜3件 |

上限は情報不足を正当化するためではなく、確認漏れ、選択肢過多、更新負担の増大を防ぐための管理基準です。実運用で変更する場合は、理由と確認体制への影響を記録します。

## 新規追加時の判断

新しい情報源やリンクを追加する前に、次を確認します。

- 既存リンクで代替できないか
- 第一版の対象地域と目的に直接関係するか
- 公式性の根拠を確認・記録できるか
- 週次・月次確認の負担を増やしても必要か
- 別のリンクと入れ替える必要がないか
- 利用者を混乱させないか
- 支援・生活再建分野の特別ルールに合うか
- 情報量上限の範囲内か

網羅性より、丁寧に維持できる範囲を優先します。未掲載は団体の評価ではなく、第一版の掲載基準および継続確認可能な範囲による判断です。

## 重複管理の防止

同じ団体、URL、公式アカウント、相談先は一つの情報として管理し、複数のページ・分野から共通参照します。想定例は次のとおりです。

- #7119：消防・救急／医療
- 熊本県公式の義援金：熊本県／支援・生活再建
- 熊本市の被災者支援制度：熊本市／支援・生活再建
- 熊本県警察の道路情報：警察／道路
- 熊本市の災害情報LINE：熊本市／消防・救急
- 熊本電気鉄道：鉄道／路線バス

具体的なデータ構造は次工程で検討し、この文書ではスキーマを確定しません。

## プライバシー説明の更新

ホスティング方式、CDN、アクセスログ、アクセス解析、Cookieは未確定です。実装構成を決定した段階で、実際の保存・処理・外部送信の有無と条件を確認し、利用者向け説明と関連文書を更新します。
