# 公開後バックログ

初版: 2026-08-04

## 目的

- 第一版公開後に行う改善、継続運用、中長期構想を一か所で管理する
- 現在実装済みの内容と、今後の候補を区別する
- 将来タスクを無制限に増やさず、着手前に目的・依存関係・完了条件を確認できるようにする
- READMEや設計文書へ細かな未対応事項を重複記載しない

この文書への登録は、実施、着手時期、仕様を確約するものではありません。着手時は現在の実装、運用負担、プライバシー、安全性を改めて確認し、必要な設計とレビューを行います。

## 第一版公開の基準点

第一版は2026年8月4日にGitHub Pagesで公開しました。正式URLは <https://madoguchi.kokoromimamori.na0aaooq.com/> です。日本語・英語、公開中2分野、3カード、14案内先を、カスタムドメインとHTTPSで提供しています。デプロイは手動workflowを使用し、初回公開後の画面・リンク・アセット・404・sitemap・HTTPS・カスタムドメインを確認済みです。

公開完了そのものは未完了バックログに含めません。

## 状態の定義

| 状態          | 定義                                                                                                         |
| ------------- | ------------------------------------------------------------------------------------------------------------ |
| `next`        | 公開後、比較的早い時期に着手する候補。すべてを同時に行う意味ではなく、着手前に個別の設計・影響範囲を確認する |
| `ongoing`     | 公開中に繰り返し継続する運用。一度完了して終了する開発タスクではない                                         |
| `planned`     | 実施する方向性はあるが、着手時期、具体的な範囲、実装方式は未確定                                             |
| `considering` | 必要性、効果、維持コスト、リスクを確認してから実施可否を決める。実施を確約していない                         |
| `deferred`    | 現時点では対応せず、再検討条件が成立した場合に見直す                                                         |
| `completed`   | 完了済み。必要に応じて未完了一覧から完了記録へ移動する                                                       |

## 項目の基本構成

各項目には、可能な範囲でID、タイトル、区分、状態、背景・目的、現在の状態、依存する項目、着手時に決めること、今回含めないこと、完了条件、再検討条件を記載します。登録前と着手前に既存項目との重複を確認します。
