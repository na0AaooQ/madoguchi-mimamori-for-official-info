# サイト構成

## 文書の位置付け

この文書は、現在実装済みのproduction画面構成と、第一版以降に検討する将来構想を区別して定めます。previewの契約は[Web画面preview MVP](WEB_UI_PREVIEW_MVP.md)、productionの生成・公開手順は[GitHub Pages手動デプロイ](GITHUB_PAGES_DEPLOYMENT.md)を参照してください。

未実装の分野・機能・表示改善の状態と着手条件は[公開後バックログ](POST_LAUNCH_BACKLOG.md)で管理します。

## 全体構成

現在のproductionは、カスタムドメイン直下に次を生成します。

| 配置   | 現在実装済みの内容                                                                  |
| ------ | ----------------------------------------------------------------------------------- |
| ルート | 言語選択ページ、`404.html`、`sitemap.xml`                                           |
| 日本語 | トップ、publishedセクションの分野別ページ、全団体・案内先一覧、プライバシーポリシー |
| 英語   | トップ、publishedセクションの分野別ページ、全団体・案内先一覧、プライバシーポリシー |

日本語は`/ja/`、英語は`/en/`へ対称に配置します。分野別ページはpublishedのセクションから動的に生成し、現在は「公的機関・防災全般」と「ライフライン」の2分野が対象です。掲載方針、確認・更新履歴、サイト内問い合わせの独立HTMLページは未実装です。サイトの目的、利用上の注意、免責事項はトップページなどに組み込み、問い合わせは言語別の外部ページへ案内します。

架空previewは`/preview/ja/`と`/preview/en/`へ生成し、productionとは入力、文言、外部リンク方針を分離します。

## トップページの導線

機関名よりも利用者の目的を先に表示し、次の流れを作ります。

1. 知りたいことを選ぶ
2. 担当する機関・事業者を確認する
3. その団体自身の公式サイトへ進む

現在のproductionトップページは次の順序です。

1. サイト名、言語切替、文字サイズ切替
2. サイトの短い説明
3. publishedの分野から探す導線
4. 全団体・案内先一覧への導線
5. サイトの目的と位置付け
6. 利用上の注意と免責事項
7. プライバシーポリシーと問い合わせへの導線

## 緊急時の案内（将来検討）

次は将来の表示候補であり、現在のproductionトップページには実装していません。

- 火事・救急・救助は119番
- 事件・事故は110番
- このサイトでは緊急通報を受け付けていない

110番・119番は、誤操作しやすい大きな発信ボタンや自動発信リンクにしません。本サイトが通報を中継するような表現も使用しません。

支援・復旧を一つにまとめるため、将来の公開画面上は約17のまとまりとなる設計です。現在のproductionでは2分野・3カードを実装しています。残る分野とカード数は将来検討であり、利用者の分かりやすさと管理上限を確認して決定します。

## 通常時と災害対応時

### 通常時

現在のproductionでは、変わりにくい常設主リンクを中心に表示します。公式SNSなどの関連案内先は詳細内に配置します。

### 災害対応時

期間限定の災害別公式案内は将来検討です。データ基盤には表示期間を管理する仕組みがありますが、現在のproductionトップページには期間限定リンクを表示していません。将来実装する場合も、人が有効性を確認した公式案内だけを対象とし、現在状況そのものは転載しません。

期間限定リンクがない場合も、災害が存在しない、安全である、対応が終了した、とは意味しません。

## カード表示

### 閉じた状態

- カードタイトル
- 短い説明
- 対象地域
- 詳細を開く操作

### 詳細表示

- 緊急時の注意
- 主な案内先と関連する案内先
- 団体名、案内先名、目的、利用場面
- 案内先の言語とURLリンク
- 公開用の補足
- 案内先確認日と公式情報確認日
- 外部サイトへ移動する旨

現在は、`details`を開いて案内先情報とURLを確認してから外部サイトへ進む設計です。閉じた状態から主リンクを利用する構成ではありません。詳細表示には`details`・`summary`の標準HTMLを使用し、JavaScriptや画像がなくても開閉と案内先リンクの利用ができます。

カードの表示は団体、案内先、関連データ、localeを組み合わせて生成します。カード自体にURL、団体名、案内先確認日、ボタン文言を直接持たせません。

## 全団体・案内先一覧

現在のproductionでは、次を一覧で確認できます。

- 正式な団体名
- 団体の説明と対象地域
- 案内先の分類、案内先名、案内内容、利用場面
- URL
- プラットフォームとアカウントID
- 案内先の言語に関する注意
- 公開用の補足
- 案内先確認日と公式情報確認日

公式性の確認根拠は管理データに保持し、公開データ生成前の内部検証に使用します。現在の利用者向けproduction HTMLには確認日を表示しますが、根拠の説明や根拠URLそのものは表示しません。自動検証の成功は、リンク先情報の正確性、最新性、完全性、網羅性を保証するものではありません。

公式SNSを確認できない場合は、その不存在を断定せず、本サイトの確認範囲を明示します。独自のサイト内検索は設けず、ブラウザのページ内検索を利用します。第一版の情報量では、検索機能の実装・保守コストより、単純で壊れにくい一覧を優先するためです。

## このサイトについて・掲載方針

現在は独立HTMLページを設けず、サイトの目的、行政公式サイトではないこと、利用上の注意、免責事項などをトップページの`details`内で案内します。プライバシーは日英それぞれのプライバシーポリシーページで説明します。

掲載方針の独立ページは将来検討です。追加する場合は、次を利用者向けに説明する設計です。

- サイトの目的と行政公式サイトではないこと
- 提供するもの・提供しないもの
- 対象地域と第一版の範囲
- 掲載基準、公式性の確認方法
- 掲載しない・保留する理由
- 掲載順が評価・推奨順位ではないこと
- 確認頻度と各確認日の意味
- 完全無料、広告なし、ログイン不要
- 新サイトのプライバシーと外部問い合わせフォームの区別
- 免責事項

## 確認・更新履歴（将来検討）

管理データには確認日や確認根拠を保持していますが、確認・更新履歴の独立HTMLページと、履歴データの利用者向け表示は未実装です。将来公開する場合も、内部メモ、未確認URL、個人情報、セキュリティ上公開すべきでない情報は掲載しません。

## お問い合わせ・修正情報

サイト内に独立した問い合わせページや入力フォームは設けません。日本語ページは外部の[日本語問い合わせページ](https://portfolio.na0aaooq.com/contact.html)、英語ページは外部の[英語問い合わせページ](https://portfolio.na0aaooq.com/en/contact.html)へ案内します。

外部フォームでは、名前またはハンドルネーム、メールアドレス、問い合わせ本文などの入力が必要です。新サイトとは別のページであり、ポートフォリオサイト側のプライバシーポリシーが適用されることを明示します。

## 外部リンク

- productionでは、公的機関・関係団体の案内先、問い合わせ先、運営者プロフィールを新しいタブで開く
- すべての外部リンクに`target="_blank"`と`rel="noopener noreferrer"`を設定する
- 外部サイトへ移動し、移動後はリンク先の方針が適用されることを明示する
- URL文字列と案内先情報を確認できる状態にする
- 「こちら」「詳しくはこちら」だけのリンク文言を避ける
- 「熊本県の防災情報を公式サイトで確認する」のように目的と移動先を示す
- PDFはリンク前にPDFであることを示す
- 災害ごとの深いURLを常設リンクとして残さない

架空previewでは、架空案内先URLと問い合わせURLをリンク化しません。運営者プロフィールだけを許可された外部リンクとし、productionの外部リンク方針と分離します。

## スマートフォンでの表示

- 基本は1カラムとする
- カードの概要を閉じた状態に残し、案内先情報とURLを詳細として段階的に開示する
- 大きなタップ領域と十分な余白を確保する
- 横スクロール前提の表を使用しない
- 色やアイコンだけで状態を伝えない
- ページ内アンカーで長いページ内を移動しやすくする
- 第一版は現在の配色1種類で提供し、その配色で十分なコントラストと可読性を確保する

ダークモードは現在のproduction公開範囲に含めません。将来対応を検討する場合も、現在の情報の読み順と可読性を維持します。タブレット・PCでの2カラムも将来検討です。
