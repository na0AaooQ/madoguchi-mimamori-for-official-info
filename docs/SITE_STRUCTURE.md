# サイト構成

## 文書の位置付け

この文書は、第一版の情報設計と画面構成を定めます。架空preview Web画面MVPでは、後述のうちトップ、分野別、全団体一覧、プライバシーポリシーを日英静的HTMLとして実装しました。本番画面と実在情報は未実装です。実装契約は[Web画面preview MVP](WEB_UI_PREVIEW_MVP.md)を参照してください。

## 全体構成

第一版は次の5ページを想定します。

各ページは日本語・英語へ対応します。架空previewでは`/preview/ja/`と`/preview/en/`を対称に配置します。productionのURLは未決定です。

| ページ                       | 役割                                                                  |
| ---------------------------- | --------------------------------------------------------------------- |
| トップページ                 | 利用者が知りたい目的から公式情報へ進む中心ページ                      |
| 公式団体・公式アカウント一覧 | 団体名、公式サイト、確認できた公式SNS、公式性の根拠と確認日を一覧する |
| このサイトについて・掲載方針 | 目的、対象、掲載基準、プライバシー、免責事項などを説明する            |
| 確認・更新履歴               | 定期確認、URL変更、追加・保留、方針変更など公開可能な履歴を示す       |
| お問い合わせ・修正情報       | リンク切れ、移転、名称変更、説明との不一致などの連絡方法を案内する    |

## トップページの導線

機関名よりも利用者の目的を先に表示し、次の流れを作ります。

1. 知りたいことを選ぶ
2. 担当する機関・事業者を確認する
3. その団体自身の公式サイトへ進む

トップページは次の順序を想定します。

1. サイト名と対象地域
2. サイトの短い説明
3. 完全無料・広告なし・ログイン不要
4. 緊急時の案内
5. 表示中の災害別公式案内
6. 知りたいことから探す
7. 5分野・約17のまとまり
8. サイト全体の最終点検日
9. 掲載方針、更新履歴、問い合わせへの導線

## 緊急時の案内

- 火事・救急・救助は119番
- 事件・事故は110番
- このサイトでは緊急通報を受け付けていない

110番・119番は、誤操作しやすい大きな発信ボタンや自動発信リンクにしません。本サイトが通報を中継するような表現も使用しません。

## 5分野・約17のまとまり

| 分野               | 公開画面上のまとまり                                                                                               |
| ------------------ | ------------------------------------------------------------------------------------------------------------------ |
| 公的機関・防災全般 | 地震・津波・大雨・警報／避難・熊本県内の防災情報／熊本市の避難・災害・生活情報／河川・洪水／政府の対応・被災者支援 |
| 命・安全・医療     | 警察・地域の安全／消防・救急／医療機関・救急相談                                                                   |
| ライフライン       | 水道・下水道／停電・電気／都市ガス／固定・モバイル通信                                                             |
| 道路・交通         | 道路・高速道路／鉄道・市電／路線バス／空港・航空便                                                                 |
| 支援・復旧         | り災証明、手続き、住まい、福祉、事業者支援、熊本県公式の義援金などを一つにまとめる                                 |

支援・復旧を一つにまとめるため、公開画面上は約17のまとまりとなります。実装時のカード数は、利用者の分かりやすさと管理上限を確認して確定します。

## 通常時と災害対応時

### 通常時

変わりにくい常設主リンクを中心に表示します。公式SNSや相談案内などは補助リンクとして詳細内に配置します。

### 災害対応時

人が有効性を確認した災害別の公式案内だけを、期間限定リンクとしてトップページ上部に表示します。トップ案内は最大5件とし、運用上は3件程度を優先します。出来事をトップ上部へ直接表示せず、必要な案内先は災害関連にも明示的に登録します。現在状況そのものは転載せず、「災害別の公式案内を掲載しています」「リンク先の最新情報をご確認ください」と案内します。

期間限定リンクがない場合も、災害が存在しない、安全である、対応が終了した、とは意味しません。

## カード表示

### 閉じた状態

- 利用目的
- 正式な機関・事業者名
- 対象地域
- 短い説明
- 主リンク1〜3件
- リンク先の対応言語
- 案内先確認日
- 詳細を開く操作

### 詳細表示

- 補助リンク
- 公式SNS、LINE、メール
- 対象地域や対象利用者の補足
- 緊急時の注意
- 公式性の確認根拠
- 期間限定リンクの掲載状態・表示期間
- 外部サイトへ移動する旨

主リンクは閉じた状態から利用可能にします。詳細表示は`details`・`summary`など標準HTMLを優先します。JavaScriptで補助する場合も、JavaScriptや画像がなくても主要リンクと詳細内容を利用できる構成にします。

カードの表示は団体、案内先、関連データ、localeを組み合わせて生成します。カード自体にURL、団体名、案内先確認日、ボタン文言を直接持たせません。

## 公式団体・公式アカウント一覧

次を一覧で確認できるページとします。

- 正式な団体名
- 公式サイト
- 本サイトの掲載基準で確認できた公式SNS
- アカウント名・アカウントID
- 公式性を確認した根拠
- 公式性確認日
- 対象地域や役割

公式SNSを確認できない場合は、その不存在を断定せず、本サイトの確認範囲を明示します。独自のサイト内検索は設けず、ブラウザのページ内検索を利用します。第一版の情報量では、検索機能の実装・保守コストより、単純で壊れにくい一覧を優先するためです。

## このサイトについて・掲載方針

次を利用者向けに説明します。

- サイトの目的と行政公式サイトではないこと
- 提供するもの・提供しないもの
- 対象地域と第一版の範囲
- 掲載基準、公式性の確認方法
- 掲載しない・保留する理由
- 掲載順が評価・推奨順位ではないこと
- 確認頻度と各確認日の意味
- 完全無料、広告なし、ログイン不要
- 新サイトのプライバシーと外部問い合わせフォームの区別
- 免責事項

## 確認・更新履歴

サイト全体の最終点検日、定期確認、URL変更、新規追加、期間限定リンクの掲載・終了、一時保留、重要な掲載方針変更を公開します。内部メモ、未確認URL、個人情報、セキュリティ上公開すべきでない情報は掲載しません。

## お問い合わせ・修正情報

新サイト内に入力フォームを設けません。任意の連絡先として、外部の[ポートフォリオサイトのお問い合わせページ](https://portfolio.na0aaooq.com/contact.html)へ案内します。

外部フォームでは、名前またはハンドルネーム、メールアドレス、問い合わせ本文などの入力が必要です。新サイトとは別のページであり、ポートフォリオサイト側のプライバシーポリシーが適用されることを明示します。

## 外部リンク

- 原則として同じタブで開く
- 団体自身の公式サイトへ移動することを明示する
- 「こちら」「詳しくはこちら」だけのリンク文言を避ける
- 「熊本県の防災情報を公式サイトで確認する」のように目的と移動先を示す
- PDFはリンク前にPDFであることを示す
- 災害ごとの深いURLを常設リンクとして残さない

## スマートフォンでの表示

- 基本は1カラムとする
- 必要情報を閉じたカードにも残し、詳細だけを段階的に開示する
- 大きなタップ領域と十分な余白を確保する
- 横スクロール前提の表を使用しない
- 色やアイコンだけで状態を伝えない
- ページ内アンカーで長いページ内を移動しやすくする
- ライト・ダーク双方で十分なコントラストと可読性を確保する

タブレット・PCでは必要に応じて2カラムを検討しますが、情報の読み順を崩しません。
