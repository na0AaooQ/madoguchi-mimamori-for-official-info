# 0008: 支援・生活再建は行政の公式情報に限定する

## 状況

災害時の支援・寄付分野では、善意の募集とともに、詐欺、不適切な募集、古い口座情報などへ案内する危険があります。本サイトで個別団体を審査・評価し続けることは目的と運用能力を超えます。

## 決定

第一版の支援・生活再建分野では、行政が公式に案内する情報だけを直接掲載します。直接掲載する金銭的支援先は熊本県公式の義援金案内だけとします。

民間団体、個人、クラウドファンディング、暗号資産、SNS上の物資・ボランティア募集などへ直接リンクしません。行政サイトが民間団体等を紹介する場合も、熊本県・熊本市の総合案内ページを経由して確認してもらいます。

## 理由

- 寄付詐欺や不適切な募集への誘導リスクを抑える
- 口座、期限、条件など変化する情報の転載を避ける
- 本サイトが団体の信頼性を審査・保証するとの誤認を防ぐ
- 人が継続確認できる範囲を守る

## 見送った案

- 民間団体独自の募金やボランティア募集へ直接リンクする
- 個人の寄付募集や物資配送依頼を掲載する
- 支援団体を評価・ランキング化する
- SNSの拡散数などを基に募集を選定する

## 安全・プライバシー・運用上の配慮

この制限は支援・生活再建分野に適用します。電気、ガス、通信、交通など公共性の高い民間事業者自身の公式情報まで行政限定にはしません。

未掲載団体を詐欺・不適切と断定しません。「第一版の掲載基準および継続確認可能な範囲による判断」と説明します。

## 将来の再検討条件

公的機関による統一的で継続的な認定・案内制度が整い、本サイトが個別団体を評価せずに安全な案内を維持できる場合に、直接掲載範囲を再検討します。

## 状態

採用
