# ADR 0024: 同一サイトを全国版へ拡張し、地域別URL移行は2県目追加前に行う

## 状況

現在の「まどぐちみまもり」は、正式ルートURLを日英共通入口とし、`/ja/`と`/en/`で熊本県・熊本市の公式情報を案内しています。将来、対象都道府県を増やす場合に、都道府県ごとの別サイトを作るか、同一サイトを全国版へ拡張するか、また地域別URLをいつ導入するかを決める必要があります。

全国版の構想と現在のBL-004を同時に実装すると、既存URL、転送、検索エンジン、内部リンク、生成成果物へ及ぶ変更が大きくなります。一方、2県目を既存の`/ja/`と`/en/`へ直接追加すると、対象地域をURLで区別できなくなります。

## 決定

- 都道府県ごとに別サイトを作らず、同じ「まどぐちみまもり」サイトを全国版へ拡張する
- 都道府県ごとの別サイトは、情報管理とサイト管理の負担が増えるため採用しない
- 複数都道府県にまたがる災害でも、関連地域の公式情報へ一つのサイトから到達できる構造を目指す
- 正式ルートURL`/`は、将来も変更しない共通入口として維持する
- 当面は熊本県・熊本市の情報充実を優先し、BL-004では全国版URL移行を実装しない
- 地域別URLへの移行は、2県目を追加する直前に実施する
- 将来は`/ja/`と`/en/`を各言語の全国トップ・地域選択画面とする
- 将来の熊本県ページ候補を`/ja/regions/kumamoto/`と`/en/regions/kumamoto/`とする
- 既存URLとの互換性、転送、canonical、hreflang、sitemap、404、内部リンク、検索エンジンへの影響は、地域別URL移行工程で別途設計する
- 地域別URL移行を現在のBL-004へ含めず、ルート画面改善と全国版移行を別工程にする

### 採用しなかった案

- 都道府県ごとに別サイトを作る
- BL-004で直ちに熊本県ページを地域別URLへ移す
- ルート画面を廃止する
- 県を追加してもURLを変えず、同じ`/ja/`と`/en/`で地域内容を切り替え続ける

## 理由

- 正式ルートURLを外部へ一貫して案内できる
- 熊本県の掲載内容充実を優先できる
- 全国展開前の現段階で不要な移行リスクを負わずに済む
- 2県目追加前に地域URLを導入することで、地域をURL上でも明確に表現できる
- 将来、利用者が対象県のURLへ直接アクセスし、共有・ブックマークできる
- 複数県災害の情報案内を一つのサイトで管理しやすい
