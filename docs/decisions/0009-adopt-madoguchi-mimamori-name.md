# 0009: 「まどぐちみまもり」の名称を採用する

## 状況

利用目的から公的機関・関係団体自身の公式情報へ案内する役割を、親しみやすく表す名称が必要です。一方、「窓口」という語は行政の公式受付、申請、相談機能と誤認される可能性があります。

## 決定

サイト名を「まどぐちみまもり」、第一版の副題を「熊本県・熊本市の公式情報案内」とします。第一版では「まどぐちみまもり｜熊本県・熊本市の公式情報案内」を基本表記とします。

行政の申請・相談を受け付ける公式窓口ではなく、「公的機関・関係団体自身の公式発表へ進むための案内サイト」であることを併記します。

## 理由

- 「まどぐち」が公式情報への入口という役割を表す
- 「みまもり」が安全を意識した穏やかな案内の姿勢を表す
- 副題に対象地域と公式情報案内であることを明示できる
- 行政公式サイトではないことを説明文で区別できる

## 見送った案

- 行政の公式窓口と誤認しやすい説明だけを使用する
- 速報・真偽判定・安全保証を連想させる名称にする
- 第一版から全国向けであると受け取られる副題にする

## 安全・プライバシー・運用上の配慮

2026年8月1日、J-PlatPatの簡易検索で「まどぐちみまもり」「公的機関・関係団体の公式情報案内」「熊本県・熊本市の公式情報案内」を確認し、同一文字列の検索結果はいずれも0件でした。

これは予備確認であり、類似商標が存在しないことや、法的に使用・登録できることを保証しません。名称や説明で、行政機関の運営、情報の正確性、安全性を保証するような誤認を招かないようにします。

## 将来の再検討条件

正式公開前または商標登録を検討する段階で、必要に応じて称呼検索、類似表記、商品・役務区分などを再確認します。法的・運用上の問題が判明した場合は、名称変更の影響範囲を記録して再検討します。

## 状態

採用
