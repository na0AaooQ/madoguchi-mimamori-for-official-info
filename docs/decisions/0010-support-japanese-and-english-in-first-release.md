# 0010: 第一版から日本語・英語へ対応する

## 状況

熊本県・熊本市に居住・滞在する英語話者や、地域外から公式情報を確認する英語話者は、日本語だけの案内では担当機関やリンク先を判断しにくい場合があります。一方、対応言語を無制限に広げると、翻訳確認と継続運用の負担が大きくなります。

## 決定

第一版から日本語と英語へ正式対応し、日本語を標準言語とします。その他の言語は将来対応とし、第一版では扱いません。

本サイト自身の案内文は日英で管理しますが、外部の公式ページ本文は翻訳、転載、要約しません。公式英語名称は根拠を確認できる場合だけ使用します。

## 理由

- 英語話者が第一版から公式情報へ到達しやすくなる
- 公開前に日英の対応関係と欠落を検証できる
- 2言語に限定することで、人による翻訳確認を継続しやすい
- 外部本文を翻訳しないため、公式発表との責任分界を保てる

## 検討した代替案

- 第一版は日本語だけとし、英語は将来対応する
- 機械翻訳だけで多数の言語へ対応する
- 不足した英語文を日本語へ暗黙にフォールバックする

## 影響

すべての公開対象について必要な日英localeを管理し、改訂関係とリンク先言語を検証する必要があります。具体的なURLパスと英語版を`/en/`へ置くかは後続工程で決定します。
