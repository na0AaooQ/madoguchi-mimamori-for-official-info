# 0005: 第一版の対象と情報量を限定する

## 状況

熊本県内には多数の市町村、団体、事業者、公式ページがあります。初期段階で網羅すると、公式性確認と定期点検が追い付かず、利用者の選択肢も過剰になります。

## 決定

第一版は熊本県全域に関係する主要機関、熊本県、熊本市、国の主要な広域情報、生活・安全・移動に直接関係する公共性の高い事業者を対象とします。熊本市以外の全市町村、全国、全事業者を網羅しません。

管理する情報源30件以内、常設・補助リンク45件以内、同時に表示する期間限定リンク8件以内を運用上の目安とします。

## 理由

- 公式性の確認、掲載、更新の運用知識を蓄積できる
- 週次・月次に人が確認できる範囲を守れる
- 多すぎる選択肢による迷いを抑えられる
- 実運用を基に段階的な拡張を判断できる

## 見送った案

- 第一版から熊本県内の全市町村を個別掲載する
- 全国対応する
- 関係する全事業者・全公式アカウントを網羅する
- 上限を設けず、見つけたリンクを追加する

## 安全・プライバシー・運用上の配慮

未掲載は市町村や団体の信頼性・重要性を評価するものではありません。「第一版の掲載基準および継続確認可能な範囲による判断」と説明します。

## 将来の再検討条件

第一版の確認手順、更新負担、利用者の要望を評価し、追加範囲を継続確認できる体制が整った場合に、地域や情報源の拡大を段階的に再検討します。
