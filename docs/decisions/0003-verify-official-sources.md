# 0003: 公式情報源の根拠と確認日を記録する

## 状況

公式SNSは表示名や認証バッジだけで判別しにくく、なりすましや名称の類似もあります。掲載根拠が不明だと、後から再確認することも困難です。

## 決定

公式サイトからのリンク、国・自治体の公式SNS一覧、公式サイト上のアカウントID、SNS開設のお知らせ、公的な組織関係などを根拠とします。対象URL、公式性を確認した根拠、公式性確認日を記録します。

## 理由

- 第三者が確認手順を追跡できる
- アカウント名やURLの変更時に再確認しやすい
- 見た目や知名度による主観的判断を避けられる
- なりすましへの案内リスクを減らせる

## 見送った案

- Xなどの認証バッジだけで判断する
- フォロワー数や表示名で判断する
- プロフィールの自己申告や投稿内容だけで判断する
- 他のSNSユーザーからの紹介だけを根拠にする

## 安全・プライバシー・運用上の配慮

公式性を確認できない場合は掲載を保留します。「公式SNSが存在しない」と断定せず、「本サイトの掲載基準に基づき、現在掲載している公式SNSはありません」のように確認範囲を示します。

## 将来の再検討条件

プラットフォームや行政機関が、より確実で継続可能な公式アカウント検証方法を提供した場合は、根拠の優先順位や確認手順を再検討します。
