# ADR 0025: productionへ必要最小限のGoogle Analytics 4を導入する

## 状況

サイトの継続利用、画面と掲載情報の改善、公式情報への案内機能、災害時等との利用傾向、メンテナンス計画を確認するため、個人を詳細に追跡しない最小限のアクセス解析が必要になりました。productionと架空データ専用previewの分離、静的HTML生成、日英の利用者向け説明、既存の再現性と安全な成果物置換を維持する必要があります。

## 決定

- Googleタグマネージャーを使わず、Google標準の静的`gtag.js`タグをproduction全HTMLと404の`head`へ直接出力する
- 測定IDは`site/production.json`の`analytics.measurement_id`だけを正本とし、欠落・空文字・前後空白・GA4形式外を生成前に停止する
- previewのLocale、HTML、公開ナビゲーション成果物へ測定IDやGoogleタグを出力しない
- ページビューとGoogle Analytics 4の拡張計測による離脱クリックだけを利用する。独自イベント、独自クリック計測、404専用イベントを追加しない
- originガード、host判定、送信抑止を追加せず、production成果物のローカル表示で生じる少量の計測を許容する
- Googleシグナル、User-ID、広告関連機能、クロスドメイン計測、内部トラフィック除外、CSP、Cookie同意バナーを初期導入に含めない
- レポートのタイムゾーンはJST、ユーザー単位・イベント単位のデータ保持期間は14か月とする
- 日英プライバシーポリシーで、利用目的、Cookie、直接識別情報を送信しないこと、Googleによる処理、広告目的に利用しないこと、拒否手段、Google公式リンクを説明する
- 自動テスト、生成、検証は外部ネットワークへ接続せず、設定値・HTML構造・追跡済み成果物を静的に検証する

## 採用しなかった案

- Googleタグマネージャーを導入する案: 初期導入に不要な管理対象と実行経路を増やすため採用しない
- 独自イベントや404専用イベントを送る案: 最小限の計測範囲を超えるため採用しない
- productionのoriginだけで動的にタグを読み込む案: 実装、テスト、運用を複雑にするため採用しない
- Cookie同意バナーを追加する案: 初期導入の合意済み範囲に含めない

## 理由

静的タグとproduction設定の単一管理により、全ページへの一貫した出力と再現性を保てます。previewを明確に分離し、日英プライバシーポリシーでデータ処理とオプトアウト方法を説明することで、必要な透明性を確保します。GoogleによるAnalytics提供に必要な処理と、運営者が解析データを第三者へ提供しないことは区別します。
