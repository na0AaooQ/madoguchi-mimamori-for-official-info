# 0004: センシティブな個人情報を扱わない

## 状況

災害時には、行方不明者、安否不明者、負傷者、患者、救助対象者、搬送先などの情報が流通します。二次掲載は本人・家族のプライバシー、安全、尊厳に重大な影響を与える可能性があります。

## 決定

利用者の個人情報を掲載情報として扱いません。行方不明者、安否不明者、被災者、負傷者、患者、救助対象者、搬送先の氏名、写真、住所、状況などを掲載・転載・推測しません。

## 理由

- 個人や居場所を特定できる可能性がある
- 本人や家族へ大きな心理的負担を与える可能性がある
- 誤情報や古い情報を二次拡散する危険がある
- 本サイトの目的は個別事案の収集ではなく、公式情報への案内である

## 見送った案

- SNS投稿を基に行方不明者情報を一覧化する
- 安否情報を利用者から募集する
- 医療機関、搬送先、救助状況を掲載する
- 個人宅への物資配送依頼を掲載する

## 安全・プライバシー・運用上の配慮

新サイト内にログイン、登録、利用者向け入力フォームを設けません。問い合わせは任意で外部フォームへ案内し、ポートフォリオサイト側のプライバシーポリシーが適用されることを区別して説明します。

ホスティング、アクセスログ、アクセス解析、Cookieは未確定であり、実装構成の決定前に不使用・不保存を断定しません。

## 将来の再検討条件

個人情報を本サイトで扱う方向の再検討は予定していません。目的変更が必要になった場合は、法令、倫理、安全、本人同意、削除手続き、管理体制を別プロジェクト相当の重大な判断として検討します。
