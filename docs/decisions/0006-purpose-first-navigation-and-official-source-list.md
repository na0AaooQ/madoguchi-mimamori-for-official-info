# 0006: 目的別導線と公式情報源一覧を分ける

## 状況

災害時には、利用者が担当機関名を知らないことがあります。一方、公式性を確認したい利用者には、団体名やアカウントIDを一覧できることが有用です。

## 決定

トップページは「何を知りたいか」という利用目的から探す導線とします。別ページに、正式な団体名、公式サイト、確認できた公式SNS、アカウントID、公式性の根拠、公式性確認日を一覧表示します。

第一版では独自のサイト内検索を設けず、一覧ページでブラウザのページ内検索を利用します。

## 理由

- 所管を知らない利用者でも目的から探せる
- 団体名から確認したい利用者にも明確な入口を提供できる
- 公式性の根拠を一覧で確認できる
- 独自検索を作らず、単純で壊れにくい構成にできる

## 見送った案

- トップページを団体名の一覧だけにする
- 目的別カード内へ全SNS・根拠を常時展開する
- 第一版から独自検索・絞り込み機能を実装する
- 検索語を外部サービスへ送信する

## 安全・プライバシー・運用上の配慮

新サイト内に利用者が確認したい内容を入力する機能を設けません。カードはモバイルで主リンクを優先し、詳細は段階的に開示します。JavaScriptなしでも主要内容を利用可能にします。

## 将来の再検討条件

一覧規模がブラウザのページ内検索では扱いにくくなり、入力データの扱い、アクセシビリティ、JavaScriptなしの代替手段を明確にできる場合に検索機能を再検討します。
